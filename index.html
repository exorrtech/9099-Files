02 / contents

19 chapters

CVE tags appear only where a chapter builds on a vulnerability verified in NVD or OSV. Everything else is anchored to published research.

  1. Direct Injection

    Prompt Injection via Tool Instructions

    Instructions embedded in content reaching model context unsanitized. Instruction precedence, multi-turn poisoning.
  2. Auth Drift

    Permission Escalation

    Capability drift between declared and actual tool scopes. Mapping what a server can really do.
  3. SSRF

    SSRF and Metadata Endpoints CVE-2023-46229

    Cloud metadata theft through tool calls, the LangChain loader pattern, Capital One anatomy at the MCP layer.
  4. Resource Exhaustion

    Context Exhaustion CVE-2023-44487

    Token bombs, window exhaustion through tool results, HTTP/2 Rapid Reset applied to agent transports.
  5. Data Poisoning

    Result Poisoning

    Contaminating tool caches and analysis outputs so downstream calls trust attacker content.
  6. Info Leakage

    Tool Behavior Leaks

    Log endpoints exposing tool arguments and secrets, timing side channels, credentials in responses.
  7. Injection II

    Server-Side Injection

    Malicious content in server responses, propagated wherever tool output is rendered or stored.
  8. Isolation Failure

    Cross-Tenant Leakage

    Tenant-ID manipulation on shared servers, context bleeding between sessions.
  9. Chained Exploitation

    Tool Chaining Attacks CVE-2024-25852

    The HugeGraph chain: no single tool vulnerable, the composition was. Sequencing calls for RCE.
  10. Description Abuse

    Tool Poisoning and Rug Pulls

    Descriptions are model instructions, and they can mutate after approval. Invariant Labs research class.
  11. Zero-Click

    Zero-Click Injection via Connectors CVE-2025-32711

    The EchoLeak class: arriving content carries instructions, auto-fetch becomes the exfil channel.
  12. Auth Abuse

    OAuth Confused Deputy CVE-2025-6514

    Token passthrough, missing audience binding, the mcp-remote redirect-to-shell injection.
  13. Dev Surface

    Insecure Dev and Debug Endpoints CVE-2025-49596

    Inspector proxies without auth, eval surfaces on localhost, every web page holding the trigger.
  14. Supply Chain

    Malicious Server Distribution

    The postmark-mcp backdoor shape: legitimate-looking package, one egress line. Typosquat distance, behavior diffing.
  15. Transport

    Session and Transport Hijacking

    Session fixation, cross-origin ID reuse, DNS rebinding against local servers. Spec requirements, tested.
  16. Data Flow

    Cross-Connector Exfil Chains

    Read from one system, write to another, until data moves somewhere it was never sanctioned. EARP class.
  17. Contract Abuse

    Schema Poisoning and Tampering

    Schemas that lie: permissive patterns, hidden properties, instruction text. Servers that validate nothing.
  18. Retrieval

    RAG Corpus Poisoning

    Instructions persisting in the retrieval layer, activating on conditions, reaching users the attacker never met.
  19. Sandbox

    Code Execution Sandbox Escape CVE-2025-3248 CVE-2024-50050

    Langflow unauth RCE, Llama Stack pickle deserialization. Measuring the sandbox you actually shipped.
